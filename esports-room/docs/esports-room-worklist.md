### 开发方式

- `floorplan-3d` 和 `esports-room` 用 Vite。端口分别是 5183、5184。
- 5173、5174 上另外两个项目没有动。
- 入口是 `esports-room/index.html`。三维在 `js/view3d.js`，Three r160。单位毫米。墙记中线，厚 200，层高 2.8 m。存档键 `esports-plans-v1`。

### 屏幕画面

- 显示器、带鱼屏、双屏、电视可以填图片、动图、视频、直链，也可以上传本地文件。
- 本地文件存在这台浏览器的 IndexedDB，库名 `esports-screen-media`。计划 JSON 里只记 `idb:` 键，不塞视频的 data URL。清除画面时不删这个库，撤销记录里还留着键。
- YouTube 观看页、分享短链、Shorts、直播走 `youtube-nocookie.com` 官方嵌入。静音、循环。站点禁止嵌入时，玻璃上是 YouTube 自己的提示。
- 哔哩哔哩视频页走 `player.bilibili.com`。支持 `BV`、`av`、分 P（`p` / `page`）。`b23.tv` 短链、番剧、直播、空间页不处理。播放器可能要点一下才开始。
- 嵌入画面按玻璃四个角做透视，跟着显示器旋转。斜着看会贴在屏幕上。比例不合时，播放器自己的黑边留在玻璃里面，并跟着屏幕一起变形。

相关文件：`esports-room/js/view3d.js`、`esports-room/js/editor.js`。

### 方向

- 后三套房间不拆 GLB，不导入模型，不用照片贴图。
- 能搬过来的是外轮廓、圆角、材质角色、一个主色。用方块、圆角盒、圆柱、旋转体画进电竞屋。
- 平面图例和三维模型走同一条记录：类型、名字、宽、深、颜色，零件可选。高度写在三维分支里。
- 木纹、烘焙光、印刷图案不画。人物、招牌文字、标志只记形状和颜色。
- 三套风格分开画，先选定一套再动手。
  - Daniel（`docs/research/2.png`，`daniels-home-office-portfolio`）：方、薄板、细金属腿。近黑、暖木、海军蓝布、铬。圆角很小。深色和浅色是两套配色。
  - 수아（`docs/research/3.png`，`sooahs-room-folio`）：厚、矮、大圆角。粉、桃木、白、浅紫。最适合程序几何。不画 Kirby，不画招牌文字。
  - Bruno（`docs/research/4.png`，`my-room-in-3d`）：干净低模色块。白柜、木地板色、深灰沙发、发光屏幕。彩灯是实时的。不抄标志。

## 提示词

在对应项目里贴上房间截图，再发下面这段。

```
按 get-prompt-from-image 看我附上的这张房间图。只读本项目，不要改文件，不要生图。

输出格式以这段话为准，不要收成一段 450–700 字的提示词，也不要写负面提示词。分析过程可以省略，结果必须逐条列出。

先用技能里的「建筑与室内」和「三维渲染」写整间房，每项一两句，只写画面上能看出的：
- 媒介边界：写实三维、半写实三维、黏土玩具，或简洁低模。排除照片、动漫、绘画。
- 机位和透视：平视、斜上、俯视；近大远小，或平行线仍平行。不写焦距和光圈。
- 光：方向、软硬、色温。暖柜灯、屏幕光、窗光分开写。
- 色彩：主色、辅色、点缀色，冷暖、饱和度。
- 建模：比例偏写实还是偏矮胖，倒角几乎没有、小，还是大，细节密度。
- 材质记忆点：哑光、木、布、金属、玻璃、陶瓷。不写软件名。
- 三到五个不能丢的视觉锚点。

然后按本项目代码里的物体名，给每件可摆放的物品一张表。墙、地、天花、水池、碰撞盒不要列入。品牌、标志、招牌文字、角色只记形状和颜色，不写名称和图样。

每件写：
- 代码里的名字，中文名，功能类（桌椅、屏幕、收纳、灯、装饰）
- 外轮廓：方或圆，厚或薄，写实或矮胖
- 圆角：几乎没有、小、大
- 4 到 8 个部件，每个注明材质角色：木、布、陶瓷、铬、黑金属、玻璃、屏幕
- 一个主色，其余用固定角色色
- 靠墙的是哪一面
- 画不出来的部分：木纹、烘焙光、贴图图案

尺寸不确定就标估算。最后用几行写出这间房共同的轮廓、圆角和主色。
```
