# 拆组工作清单

项目：`my-room-in-3d`  
范围：从烘焙房间壳体里拆出可单独爆炸、单独列出的物体  
结果：爆炸视图 24 个资产，房间壳体 39,527 面留在原位

## 视图

- [x] 爆炸视图：整组移动，壳体不位移
- [x] 列表视图：分类、面数、搜索、单击选中、双击对准
- [x] 组装视图：各组回到原始世界位置
- [x] 帧率面板不再挡住按钮

## 已拆出的物体

### 屏幕和灯

- [x] 电脑：机身 150 面 + 视频屏幕。支架是两只红头支脚和中间底板，不是麦克风杆
- [x] Mac：机盖、白底座和屏幕。没有把龟背竹的叶子算进去
- [x] 电视：右墙屏幕板，弹跳标志挂在电视上一起走，118 面。只切贴墙的薄片
- [x] Elgato：灯头加摇臂
- [x] Google Home：机身加 4 颗灯，位置在地板附近

### 桌面

- [x] 电脑桌：台面加桌下挡板和前缘，5,658 面，宽 3.53
- [x] 键盘：键帽，另加桌面上那块约 0.50 × 0.25 的深色贴图卡片
- [x] Loupedeck：底座加 14 个按键
- [x] 耳机：桌面上的耳罩，40 面。麦克风架长杆仍是独立的一组，1,398 面
- [x] 杯子：杯身加热气
- [x] 魔方：28 面，没有并进耳机

### 家具

- [x] 书架：层板和前面的收边，6,809 面
- [x] 书：按薄的那一轴认，880 面
- [x] 沙发：坐垫加上外皮，10,462 面，约 2.28 × 1.80 × 5.90
- [x] 茶几：沙发前的白桌子，台面加矮箱，2.12 × 0.74 × 2.95
- [x] 手柄：茶几上的手柄，上下两层合成一只，3,804 面
- [x] 电视柜：地面垫板到上层搁板，只在电视正下方，3,956 面
- [x] 转椅：椅座仍单独旋转，底座（气杆、五爪、轮子）跟着一起爆炸，合计 15,758 面

### 装饰

- [x] 相机
- [x] 龟背竹：叶子加两根茎
- [x] 吉他：含琴颈
- [x] Among Us 小人

## 拆的时候守住的边界

- [x] 岛只按中心是否落在物体内认，没有按间隙把相邻岛并成一团
- [x] 包围盒只用索引用到的顶点
- [x] 硬切按顺序做，盒子互不重叠。一块三角面只进一个物体；切剩的碎片回到壳体
- [x] 电视只收厚度约 0.12 的墙面，柜子在墙前面，两边不抢面
- [x] 键盘底下那块大黑影、显示器底下那块大黑影留在桌面上。只有键盘那块小深色贴图做成了卡片
- [x] 原先已对过的电脑、Mac、植物、吉他、书、Among Us、椅子轮子，尺寸没有被后面的切割改掉

## 仍然留在壳体上

- [ ] 鼠标：没有独立网格
- [ ] 键盘主体：除了键帽和那张小卡片，其余是桌面贴图
- [ ] 显示器增高架：就是电脑上那两只红头支脚，没有第二件
- [ ] 咖啡：就是杯子，没有另一件
- [ ] 电视柜上的 Switch、Xbox、Wii 和绿植：碎面分不出各自的壳，跟着柜子走
- [ ] 书架贴墙的整条立柱：和墙是同一条长面
- [ ] 沙发尽头那截更高的柜子
- [ ] 靠书桌那侧的矮柜：不在电视正下方，没有并进电视柜
- [ ] 窗边的白垫子和骨头：还在壳体上
