# daniels-home-office-portfolio 深色房间规格

对照图是仓库里的 `docs/research/2.png`。物体名来自 `src/Experience/parts/catalog.js`、`objectLabels.js`、`objectVolumes.js`。墙、地、天花和结构块不列入。品牌、标志、招牌文字和角色只记形状和颜色。

尺寸都是按画面比例的估算，单位厘米。没有单独 id 的，写运行时会用的标签。角色色固定为：木＝暖木，布＝海军蓝或深灰，陶瓷＝白或褐，铬＝银，黑金属＝近黑，玻璃＝透明，屏幕＝冷白发光面。近黑的板件用各件自己的主色，角色色只用于木、布、陶瓷、铬、玻璃和屏幕。

## 整间房

- **媒介边界：** 写实三维。两面墙的开口模型，浮在黑底上。排除照片、动漫和绘画。
- **机位和透视：** 斜上方看向内角，近处两面是空的。平行线仍平行，没有近大远小。
- **光：** 环境光弱、偏冷，影子软。右墙柜子里是暖色软光。桌面屏幕有一小块冷白光。没有窗光。落地灯灯罩是局部的暖白。
- **色彩：** 主色近黑，饱和度低。辅色是暖木和海军蓝布。点缀是地毯上的橙、灰、米白，以及铬和绿色植物。
- **建模：** 比例接近写实，不矮胖。倒角小。叶子、椅轮、钟的辐条都在，细节偏密。
- **材质记忆点：** 大面积哑光黑。木是暖色直纹。沙发和椅面是布。椅脚是铬。架子上有玻璃罩和陶瓷罐。屏幕是发光板。
- **不能丢的锚点：** 开口的黑底内角。右墙整面暖光木架。左墙木条、线框钟、深蓝沙发和三脚灯。书桌、曲面屏、铬脚椅子，压在橙灰色块地毯上。

左墙指有木条和钟的那面，右墙指通高架子的那面。

## 全房共同

外轮廓是方盒子、薄板、细金属腿。圆角小，几乎没有大圆角。主色近黑，辅色暖木和海军蓝布，点缀是铬、橙灰色块和柜子里的暖光。
