# daniels-home-office-portfolio 浅色房间规格

对照图是仓库里的 `docs/research/2-white.png`。物体名来自 `src/Experience/parts/catalog.js`、`objectLabels.js`、`objectVolumes.js`。墙、地、天花、窗框和结构块不列入。品牌、标志、招牌文字和角色只记形状和颜色。

尺寸都是按画面比例的估算，单位厘米。没有单独 id 的，写运行时会用的标签。角色色固定为：木＝浅木，布＝白，陶瓷＝白，铬＝浅灰亮，黑金属＝近黑，玻璃＝透明，屏幕＝冷白发光面。白漆家具用各件自己的主色，不改记成黑金属。

## 整间房

- **媒介边界：** 写实三维。两面墙的开口模型，浮在浅灰底上。排除照片、动漫和绘画。
- **机位和透视：** 斜上方看向内角，近处两面是空的。平行线仍平行，没有近大远小。
- **光：** 主光从右墙窗户进来，软，偏暖白，影子淡，落向左前方。屏幕只有一小块冷白，照不亮桌面。没有暖柜灯。
- **色彩：** 主色白，饱和度低。辅色是浅木地板和木家具。点缀是绿植、浅粉挂画、一只浅蓝靠垫，以及地毯上的黑菱形。
- **建模：** 比例接近写实，不矮胖。倒角小。叶子、靠垫和抽屉都在，细节偏密，表面干净。
- **材质记忆点：** 墙和大家具是哑光白。地板、茶几、壁架是木。沙发和椅子是布。罐和瓶是陶瓷。窗是玻璃。屏幕是发光板。细腿是浅木，不是铬。
- **不能丢的锚点：** 开口的浅灰底内角。左墙白砖、木壁架、浅粉大画和白布挂饰。白色 L 形书桌和浅木腿椅子。右墙窗户、白沙发、木茶几和黑菱形地毯。

左墙指砖墙那面，右墙指有窗的那面。
