# 家具绘制

把一段文字或一张实拍，拆成这个户型页里已有的那套图例和模型。新造型写在 `floorplan-3d/js/plan.js` 的 `LIB`、`js/furniture.js` 的 `furnSVG`、`js/view3d.js` 的 `buildFurniture`。不改 `demo/index.html`，不引入 glTF，不给家具贴照片贴图。

把图上已有家具摆进某个房间，不在这里做。那是 [huxing-pack](../huxing-pack/SKILL.md) 的 `furniture`，每一件要带 `roomId`。

已有类型的造型见 [types.md](types.md)。几何小工具和材质角色见 [primitives.md](primitives.md)。

## 先判断做不做新造型

记录只有这些字段：`{id, type, name, cx, cy, w, d, rot, color}`。宽深单位是毫米，颜色是一件家具的主色。

- 轮廓、开门方向、座位数能用现有 `type` 表达：只在 `LIB` 加一条 `[type, 中文名, 宽, 深, 主色]`。不要复制 `furnSVG` / `buildFurniture` 的分支。
- 现有分支对不上（折叠床、吧台椅以外的新物种、明显不同的构造）：新增一个小写英文 `type`，两处 `switch` 同时写，并在 `LIB` 登记。缺任何一处，平面和三维会各画各的。
- 用户只想看拆解、没说要放进页面：写出拆解后停止，不改文件。

尺寸不确定时用该品类的常见毫米，并在回复里写明是估算。不要为了凑一张照片去改墙体或其他家具。

## 解析

文字：取出品类、件数、宽×深×高、主色、要靠墙的那一面、可活动的部分（门、抽屉、靠垫）。高度不进记录，只进三维分支。

图片按这个顺序看，不要描述品牌和logo：

1. 外接矩形。靠墙的一面是背面。
2. 主材只有一种，它成为 `color`。其余材质收成固定角色：木、布、陶瓷、铬、黑金属、镜、玻璃、屏幕。花纹、木纹、印花都丢掉。
3. 拆成 4 到 8 个部件。每个部件要能落到 `box` / `rbox` / `cyl` / `lathe` / `rod` / `tube` / `blob` / `shell` 上。
4. 用画面里的已知参照估毫米：门洞约 900，座椅坐宽约 450–550，单人床宽约 1200、双人 1500 或 1800，进深通常 2000。估不出就用 [types.md](types.md) 里的同类默认值。
5. 照片里被挡住的腿、拉手、抽屉数量，按可见节奏补齐，不发明第二套结构。

回复里先给这一份拆解，再改代码：

```
名称 / type / 分类
宽×深 mm，主色
背面：哪一条边靠墙
部件：名称，材质角色，大约尺寸
沿用现有分支，或新增分支的原因
```

## 统一风格

暖、哑光、少色。主色从已有库里挑，不要高饱和：

- 布艺：`#c9d6df` `#d8c7dc` `#e8d5b5` `#b7c4b0` `#c3cbd6` `#d6b99a` `#e0b98f`
- 木：`#e2cfb4` `#e8dccb` `#d8c2a2` `#d9c3a3` `#efe6d8` `#e6dccc`
- 石/瓷/金属壳体：`#e9e5de` `#eef1f3` `#eef3f6` `#dfe4e8` `#ffffff` `#f6f7f8`
- 深色点缀：`#3d3a34` `#4a4f55` `#6b5d4c` `#1d1d1f` `#1f1d1b`

一件家具只让 `color` 覆盖最大的那块面（床品、坐垫、柜门、台面）。框架、腿、拉手、屏幕用固定色，这样换色时不会把螺丝也染成布的颜色。

轮廓线只有一种：`#3d3a34`，1px，`vector-effect: non-scaling-stroke`。圆角表达软硬：布和垫 `rx` 40–80，台面板 20–30，柜体可以不圆角。虚线只表示玻璃、打开的隔架，或漂在物体外面的气流，不表示阴影。

装饰只放一到三件小物（书、杯、花瓶、台灯）。花瓶和书架用已有的 `vase`、`R` 随机，种子来自宽深和坐标，同一件家具每次长得一样。

## 朝向

局部原点在平面中心。背面是靠墙的那条边。

- 平面：背面在局部 `-y`（图例上方），正面在 `+y`。`translate(cx,cy) rotate(rot)`，角度顺时针。
- 三维：背面在局部 `-z`（`bz = -d/2`），柜门、屏幕、坐垫朝 `+z`。`box` / `rbox` / `cyl` 的 y 是底面高度，不是中心。组的位移和 `rotation.y = -rot` 由 `buildFurniture` 在 `switch` 之后统一设置，分支内部不要改 `g.position`。
- 宽 `w` 沿局部 x，深 `d` 沿局部 y / z。毫米进分支前先 `M()`，除以 1000。

床头、沙发背、柜体靠墙边必须落在背面。若实拍的门在侧面，那是旋转 90° 的摆放，不是新的局部坐标。

## 平面图例

在 `furnSVG(t, w, d, c)` 加分支。`x = -w/2`，`y = -d/2`，`m = min(w,d)`。只用现成的 `rc`、`ec`、`ln`、`pa`、`shade`、`ST`、`DASH`。返回拼接好的 SVG 字符串。

画的顺序：

1. 外轮廓，填主色或深一档的框架色 `shade(c, .85)` 或 `shade(c, .78)`。
2. 背面的厚边：床头约 `min(90, d*0.05)`，沙发背约 `d*0.24`，扶手约 `min(200, w*0.13)`。
3. 正面的分件：坐垫、床垫、抽屉缝。件数由宽度决定，不写死，除非结构就是一件（单人沙发、圆桌）。
4. 一个功能符号：灯是同心圆，植物是圆加叶，灶是火盖，水槽是两个白盆加龙头，玻璃是对角线虚线。
5. 总形状控制在大约 15 个以内。小件（`min(w,d) < 380`，以及植物、落地灯、边几、吧椅、懒人沙发）不要名字，需要时把 type 放进 `NOLABEL`。

缝用一条线，或一块内缩矩形。不要渐变，不要滤镜，不要把三维投影画进平面。

## 三维模型

在 `buildFurniture` 的同一个 `type` 上加分支。顺序固定：

1. 定材质角色。布 `fabric(c)`，木 `woodM(色)`，需要反射的金属用 `chrome` / `blackMetal` / `metal` / `hwMat`，陶瓷 `ceramic()`，镜子 `mirror()`，屏幕 `screenMat(微光色)`，发光罩 `glowMat`。柜门缝后面垫一层 `#2a2724`，这是 `fronts()` 已经做的。
2. 落地结构。有腿就 `legs(g, w, d, 高, 材质, 内缩, 底半径)`，腿顶略粗。贴地柜用 60–100mm 的深色踢脚，不要四条腿再加踢脚。
3. 主体。软的用 `rbox`，圆角 12–70mm；硬板用 `box` 或很小的圆角。坐垫、靠背可以 `rot(..., 小弧度)` 微微后仰，角度约 0.12–0.3。
4. 门和抽屉一律 `fronts(g, x0, y0, w, h, z, 列, 行, 材质, 拉手, 拉手高度)`。拉手：`bar` 金属条，`knob` 圆钮，`edge` 上沿暗槽。区域高度小于 0.4m 且比宽更扁时，它会被当成抽屉。
5. 台面比柜身宽出约 10mm，厚 25–40mm。
6. 最后加小物。小物不得超出平面外接矩形太多，否则平面和三维对不上。

高度用米，不跟宽深一起缩放，只用宽深决定个数和分件宽度。常用高度：

| 部位 | 米 |
| --- | --- |
| 餐椅座 / 沙发座垫顶 | 0.44 / 腿高约 0.12 再加座垫 |
| 餐桌、圆桌台面底 | 0.715，台面厚 0.035 |
| 书桌台面底 | 0.72 |
| 床箱 / 床垫 | 0.30 / 0.22 |
| 床头板 | 1.08 |
| 矮柜、电视柜、浴室柜门 | 0.85、0.40、0.45 |
| 衣柜、高柜 | 2.2、蒸烤箱柱 2.1 |
| 冰箱 | 1.8 |
| 吊柜底 | 约 1.48，自身高 0.7 |

分件数：`Math.max(1, Math.round(w / 模数))`。衣柜门模数约 0.5m，沙发位在宽大于 2.2m 时为 3，否则 2，单人沙发恒为 1。双枕条件是宽 ≥ 1.3m。

玻璃用模块里已有的 `glassMat`，窗框用 `frameMat`。透明物体关掉投射阴影。默认分支是 0.8m 高的方块，新家具不能留在默认分支。

## 示例

输入：「一张浅灰布双人床的照片，床头有竖条软包，床尾搭深色毯。」

拆解：沿用 `bed`。1800×2000，主色 `#c9d6df`。背面是床头。已有分支含床箱、床头竖条、床垫、被、床尾巾和双枕。只在「卧室」加一条库条目，不新写几何。
