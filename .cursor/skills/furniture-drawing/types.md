# 已有家具类型

`LIB` 条目是 `[type, 中文名, 宽mm, 深mm, 主色]`。同一 `type` 可以有多条不同尺寸。平面在 `furnSVG`，三维在 `buildFurniture`。背面都在平面的上方、三维的 `-z`。
