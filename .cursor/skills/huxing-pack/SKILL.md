# 户型数据包

识图之后只交一份 JSON。不要改这个项目的代码，不要描述成要手画进编辑器。用户把这份 JSON 贴进户型页的「AI 识图」。

单位毫米。北在上方，y 向下增大。墙是中线。西、北最外中线是 0。坐标不要出现大段负数。

## 只输出这一份

回复里放一个 `json` 代码块，块外不要再出现第二个 JSON。

```json
{
  "kind": "huxing-pack",
  "version": 1,
  "name": "三室一厅一卫",
  "walls": [
    {"id": "wN", "a": [0, 0], "b": [4000, 0], "thick": 200, "type": "e"}
  ],
  "openings": [
    {"id": "d1", "kind": "door", "wallId": "wS", "t": 1500, "len": 900, "head": 2100, "hinge": "start", "swing": 1, "entry": true}
  ],
  "bays": [
    {"id": "bay1", "wallId": "wN", "t": 800, "len": 1800, "depth": 620}
  ],
  "rooms": [
    {"id": "living", "name": "客厅", "mat": "wood", "at": [2000, 3500]}
  ],
  "dims": [],
  "furniture": [
    {"roomId": "living", "type": "sofa", "name": "三人沙发", "cx": 2000, "cy": 4200, "w": 2400, "d": 900, "rot": 0}
  ]
}
```

`furniture` 可以为 `[]`。有家具时，每一件都必须有 `roomId`，而且等于上面某个 `rooms[].id`。没有 `roomId` 的家具不会被导入。

## 墙

`{id, a:[x,y], b:[x,y], thick, type}`

- `thick` 按这一面墙写。外墙和隔墙写 200。飘窗、凹槽的侧墙写 100。
- `type`：外墙 `e`，隔墙 `n`。图纸标了承重才用 `b`。矮墙 `low`。
- 端点相接，偏差不超过 2。隔墙端点落在另一条墙的中线上。同一道墙只写一次。
- 直墙默认水平或垂直。斜墙只在图纸明显不正交时使用。弧形墙没有弧线字段，沿弧的中线分成几段直墙，弦到弧的空隙不超过大约 50 毫米，端点相接。门扇的开启弧线不是墙。墙角只是小圆角、尺寸仍按直角标时，写两条直交墙，圆角写进 `notes`。

先画外轮廓，再放门窗。印刷数字就是毫米。每一边从西、北最外中线 0 起逐段累加，刻度指着的墙，中线就等于这个累计值。不要再加减墙厚。东、南最外中线是这条链的总累计，这道外墙全程都用这个数。少了几百毫米的错台另起一条墙，只放到短杠指着的那道墙角上。

不要整张图乘一个像素比例。不要把一边加总后当成整栋的总宽或总高。上下、左右的合计可以不同，因为外轮廓常常是错台。上边的合计不是底边的长度，底边的合计不是东墙的 x，较长的竖向合计不是总高。

同一边有两条尺寸链时，用刻度正好落在这侧墙角的那一条。另一条写进 `notes`。不要平均，不要把某一段改成看起来更像墙距的数。

刻度落在墙角上。轮廓退进或凸出一截，哪怕只有两三百毫米，也要另起一条墙。禁止为了把房间收成矩形而抹掉错台，或把底边拉成一条通长的南墙。只有图上同一条连续直线才共用一个 x 或 y。

像素刻度和印刷毫米怎么钉成墙面，按 [floorplan-from-image](../floorplan-from-image/SKILL.md) 做。用户只附户型图。某张图钉完之后的锚点见 [examples.md](../floorplan-from-image/examples.md)，不要把那张图的数字写进给外部模型的提示词。

## 门、窗、推拉门

`{id, kind, wallId, t, len, head, sill?, hinge?, swing?, entry?}`

- `t` 是离 `wall.a` 的距离，`len` 是洞宽。两端至少留 10。
- 窗 `kind:"win"`，`head` 2400，普通窗 `sill` 900，高窗约 1400，矮窗约 450。
- 门 `kind:"door"`，宽约 750–900，`head` 2100。`len` 量到两侧墙垛恢复厚度的地方。只量墙带中间的白缝时，门框算进了墙里，洞宽会偏短。`hinge` 为 `start` 或 `end`。`swing` 为 `1` 或 `-1`，弧开向房间。整张图只有一樘 `entry:true`。
- 推拉门 `kind:"slide"`。到顶时 `head` 2400，否则 2100。

## 飘窗

外墙上的玻璃凹室不要另画三面墙。

`{id, wallId, t, len, depth}`，`len` 至少 500。`depth` 按图上凸出外墙的尺寸写，不要几处都写成 620。飘窗房间 `counted:false`，`mat` 用 `marble`，图纸地面和卧室一样时跟着卧室。

## 房间

`{id, name, mat, at, counted?}`

`at` 是房间内部的一点，不要落在墙上。导入靠这一点把名字贴上算出来的净轮廓。

| 图纸 | mat |
| --- | --- |
| 木地板、卧室、起居 | `wood` |
| 深色木 | `walnut` |
| 客厅大砖 | `tile800` |
| 厨房地砖 | `tile600` |
| 卫生间、阳台湿区 | `antislip` |
| 石材、飘窗 | `marble` |
| 水磨石 | `terrazzo` |
| 地毯 | `carpet` |

按图上的颜色选，不要按房间名字选。和卧室同一色的起居用 `wood`，不要因为叫客厅就用 `tile800`。湿区不要用 `wood`。没有把握用 `tile800`。面积按墙内皮，飘窗不进套内。

## 尺寸

`dims` 留空，导入后按墙中线现算。印刷分段是墙面到墙面，不要写进 `dims`。一段链的形状是：

`{horiz, at, start, segs}`

- `horiz` true 沿 x，false 沿 y。
- `start` 是第一道刻度，落在墙中线上。
- `segs` 相加等于这条边的跨度。墙厚不要单独成段。
- `at` 是尺寸线所在的另一轴位置，放在房子外侧约 800。

只标外轮廓。门窗洞宽不写进尺寸。

## 家具

每件：`{roomId, type, name, cx, cy, w, d, rot}`

- `roomId` 必填，等于 `rooms[].id`。一件家具属于哪个房间，只看这个字段。
- `cx, cy` 是平面中心。`name`、`w`、`d` 必须用下面库里的某一行，不要按像素自造尺寸。
- `rot` 顺时针。0 时背面朝北（局部 `-y`）。背面贴所靠墙的内皮，中心离内皮 `d / 2`。

## 交卷前核对

这些条不过就改坐标，不要交。

- 图上凸出外墙的窗有几处，`bays` 就有几条。凸出的窗不要写成普通 `win`。
- 每扇门窗都在图上那条墙上。窗在东墙就不要写到北墙。弧线贴着哪条墙，门就在哪条墙。
- 图上没有的洞不要补。实墙保持实墙。
- 没有用一个像素比例乘整张图。每一段用它自己的印刷数字，累计值直接写成中线，没有再加减 100 或 120。没有把某一边的合计当成整栋总宽或总高，也没有把两条尺寸链平均。错台还在，外轮廓不是被收成的矩形。没有长度为 0 或完全重合的墙。`notes` 写了用哪条链、舍了哪条。
- 只有图上同一条直线的墙才共用坐标。
- 窗的 `len` 接近图上玻璃的长度。一面宽窗不要无故写成 800 或 1200。`t` 按玻璃起点估，不要放到墙中央凑数。
- 家具先看背面靠哪条墙，再定 `rot`。床头、沙发背贴着那条墙的内皮，中心离内皮 `d / 2`。中心必须落在 `roomId` 那间里面。
