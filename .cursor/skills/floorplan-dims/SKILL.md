# 户型周边尺寸线

识图要交给项目导入时，尺寸写在 [huxing-pack](../huxing-pack/SKILL.md) 的 `dims` 里，不要改代码。链的字段和下面「一条链」相同。`dims` 留空时，导入后按墙中线现算。

这份技能管项目里怎么画这些链。周边尺寸只画建筑外轮廓。改 `floorplan-3d/js/plan.js` 和 `floorplan-3d/js/editor.js`。用户随手拉的测量是 `state.measures` / `renderMeasure`，不要和尺寸链混在一起。

单位毫米。SVG 的 y 向下，北是 y 更小。

## 用哪一套链

`planDimChains(plan)` 按这个顺序，命中即停：

1. `plan.dims` 有条目：用手写链。
2. `presetDims` 为真：返回 `null`。`renderDims` 改画写死的三室两厅两卫原图链。
3. 其余：`shellDims(walls)` 按当前墙现算。不要把结果写回 `plan.dims`。

「尺寸」按钮只改 `#gDims` 的 `display`（`ui.layers.dims`）。关掉图层时链还在。

## 一条链

`{horiz, at, start, segs}`

- `horiz`：横链沿 x，竖链沿 y。
- `start`：第一道刻度，落在墙中线上。
- `segs`：相邻刻度的间距。相加必须等于这条链的跨度，中间不能缺一段。
- `at`：尺寸线在另一轴上的位置。

`renderDims` 的 `chain` 把文字画在 `at - 70`，也就是坐标减小的那一侧。上、左的文字在线外侧；下、右的文字在线和房子之间。刻度垂线是 `at ± 170`，斜刻 `± 80`。字号：分段小于 400 用 140，否则 200。竖链文字 `rotate(-90)`。颜色 `#7d7160`，线宽 1，斜刻 2，`vector-effect: non-scaling-stroke`。

## 原图：三室两厅两卫

`seedPlan` 设 `presetDims: true`，`dims` 为空。数字是图纸外皮，墙厚单独成段。没改过墙时不要重算，也不要改这些数：

- 上：`1580/240/2760/240/1540/240/3670 = 10270`，线在 y = -750；总长在 -1250
- 下：`2180/240/2160/240/5450/240/1340 = 11850`，线在 y = 11350；总长在 11850
- 左：`3370/1580/240/2770/240/2360 = 10560`，线在 x = -800；总长在 -1300
- 右：`3370/240/2760/240/3950 = 10560`，线在 x = 12750；总长在 13250

上下总长不一样，因为南北外轮廓不是同一条边。

## 手写链

三室一厅一卫的 `beikePlan` 自带一份中线 `dims`。本地存档 `huxing-plans-v2` 用 `rev` 决定要不要整份替换。为了刷新尺寸去抬 `rev`，会丢掉用户改过的飘窗、房间名和家具。`dims` 空了就让 `shellDims` 现算。

## 自动链 shellDims

输入是当前 `walls`，包含 `refreshBays` 生成的飘窗墙（厚 100，进深默认 620）。

1. `extractFaces(walls, {keepHull:true})` 取出外环：面积最大，且不小于其余面之和的 98%。外环顶点在墙中线上。
2. 只认轴对齐边，偏差 2mm 以内。斜边不参与分段。整圈都取不出外环时，四边各一道中线总长，位置仍按下面的外皮间距。
3. 四边各看自己的轮廓，不把所有内墙坐标都投上来：
   - 上：每个 x 区间里最北的水平边（y 最小）
   - 下：最南（y 最大）
   - 左：最西（x 最小）
   - 右：最东（x 最大）
4. 刻度有两种。轮廓高度或左右位置变了的那个坐标。还有落在这一侧轮廓边上的外环顶点。内墙如果 T 接外墙，外环会被切开，接点因此入刻度。没贴上这一侧轮廓的内墙和凹角，不进这一侧。
5. 坐标差 1mm 以内合并。分段四舍五入成整数。
6. 内链离墙外皮 780。外皮来自 `wallQuad` 的包围盒，只决定线往外推多远，不改变刻度。分段多于一段时，再沿离开房子的方向加 520，画一道总长。只有一段时不加第二道，避免同一个数出现两次。520 不能再缩小，否则总长文字会压住内链。

飘窗算在外轮廓里。凸出的进深和窗宽会变成那一侧的分段，总长跟着变宽变高。

墙厚不单独成段。自动链量的是中线到中线，和原图那套「240 单独成段」不是同一种标注。

## 视口

`fitBounds` 要把 `planDimChains` 的端点包进去，再留 800。`normalizePlan` 对非原图户型重算 bounds。原图户型保留手写 bounds，否则写死的尺寸线会被裁掉。

## 墙一改，手写链作废

`touchShell`（画墙、删墙、改厚、门窗、飘窗）做三件事：`presetDims = false`，`dims = []`，然后重算房间并 `fitBounds`。下一帧走 `shellDims`。不要在这里把算好的链存回去。

## 不要做

- 不要给每道内墙都标一圈。
- 不要把门窗洞宽写进周边尺寸。
- 不要改 `renderMeasure`。
- 不要让没改过墙的三室两厅两卫改走自动链。
- 不要把自动链的中线数，改成原图那种墙厚分段，除非四边的外皮偏移一起改，并且 `geomSelfCheck` 的断言一起改。

## 自检

`geomSelfCheck` 里这三组必须保持，改规则时连断言一起改，并说明数字为什么变：

- 中线 10000×8000 的矩形：上边一段 `10000`，没有第二道总长。
- 顶边中点 T 接一道没到底的隔墙：上边 `5000,5000`。
- 三室一厅一卫、没有飘窗：上 `2135,2450,1906,1285`；下 `2135,3105,2536`；左 `2235,5736,2119`。
