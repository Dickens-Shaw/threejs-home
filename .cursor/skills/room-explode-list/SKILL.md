# 房间爆炸与平铺列表

三种查看方式：`assembled` 组装、`exploded` 爆炸、`list` 平铺。组装时藏起列表面板。爆炸和列表都打开面板。

现成实现：

- 已拆成独立物体：`my-room-in-3d/src/Experience/AssetViews.js`
- 一份 GLB 里很多网格：`sooahs-room-folio/src/asset-views.js`

## 认出参照主体

爆炸的方向、推出距离和相机取景只认一件紧凑的房间。不要用最大的网格，也不要用全场景质心。

1. 列出候选壳体：用户称为主体的网格、名为 `First` / `room` 的壳体、或包住家具的烘焙块。
2. 在网格仍可见时量世界 AABB。`Box3.setFromObject` 会跳过不可见物体。
3. 参照主体是家具所在的那间小房间。包围盒比家具簇大出数倍的平面、投影承接面、超大烘焙块都排除。sooah 的参照是网格名 `First`；`Second` 是巨大平面，用它会把物体推到地平线。
4. 参照点取主体中心，或房间内部的一个固定点。my-room 的锚点是 `baked.model.mesh`，推出方向用房间内的 `(1.05, 2.2, -2.3)`，不用壳体的巨大包围盒。
5. 每一块结构壳体都是锚点，爆炸位移为 0。sooah 的 `First` `Second` `Third` `Fourth` 都不动；取景只包含 `First` 和炸开的道具，其余壳体不进爆炸包围盒。
6. 推距和抬高按参照主体算，不按全体壳体的并集算。sooah：`push = max(主体半径 × 0.95, 0.8)`，`lift = max(主体半径 × 0.18, 0.15)`。物体已经拆开、尺度已知时，用短的固定推出（my-room 单件约 5.4，成组约 4.6–4.8，抬高约 1.25–1.6）。

## 爆炸

锚点：`explodePosition = homePosition`，不画引线。

其余资产：

1. 方向 = 资产中心（或成组质心）− 参照点。Y 分量先乘 `0.2` 再归一化，避免向下穿地。方向过短时，改用水平环上的单位向量，Y 取小的正值。
2. 落点 = 原中心 + 方向 × push，再向上加 lift。落点 Y 不得低于原中心 Y。
3. 重复件先成组再分开。组内保持相对位置，需要时沿 Y 排开（灯珠、按键）。单件各自沿自己相对参照点的方向推出。
4. 做约 24–28 轮两两分离。半径用尺寸的一部分，并加上小间隙。分离后再次把 Y 夹回不低于原中心。
5. `explodePosition = explodedCenter − centerOffset`。`centerOffset` 是包围盒中心减去物体 `position`。

引线只在爆炸模式出现，从 `homeCenter` 连到当前中心，不参与射线检测。隐藏的资产把线段收成一个点。相机从斜上方看参照主体和附近道具，方向约 `(1, 0.92, 1)`，极角上限约 `0.42π`，不能钻到目标下方。

离开组装前保存相机。放宽轨道限制后再播放位移动画。回到组装并播完后，先写回最终位姿，再恢复原来的轨道限制。布局期间每帧把 `layoutPosition` / `layoutScale` 写到物体上，并暂停椅子、鱼、标志这类自主动画。不要改旋转。

`不位移` 只约束爆炸。平铺时锚点也进网格。

## 列表明细

面板标题是「可拆分资产」。摘要写：`N 个资产。{锚点名}留在原位，其余在爆炸视图里分开。`

分组后每组一个标题和数量。组内编号从 `01` 重新计。一行两层：

```
01  名称
    类型 · 不位移 · 源文件.glb · 12,345 面
```

明细用这个顺序，空段去掉，段之间是 ` · `：

`[类型, 锚点 ? "不位移" : "", 源文件, 面数.toLocaleString("en-US") + " 面"]`

面数遍历该资产下的网格：有索引用 `index.count / 3`，否则用 `position.count / 3`。

分组按资产本来的切分方式，不要混用：

- 物体已经按文件拆开：按类型分组，例如基准、屏幕、灯光、控制台、装饰。每行的文件名是它自己的 glb。
- 全部网格在一个 glb 里：按贴图块分组，例如第一块、第二块、第三块、第四块，没有块后缀的归入其他。文件名整列相同。类型从网格名判断（结构、屏幕、家具、装饰、钢琴、键盘）。名称用中文，保留编号；专有名可保留原文。

每个能分开的网格单独一行，包括默认隐藏的部件和成组爆炸里的每一颗灯珠、每一个琴键。搜索匹配名称、类型、文件、明细和原始网格名。单击选中，双击把相机对准该物体，圆点切换可见，Escape 取消选中。搜索框有焦点时不响应 Escape。

## 平铺

列表模式把全部资产放到同一高度的方格上，不再保持房间里的相对位置。

- `columns = ceil(sqrt(数量))`，`rows = ceil(数量 / columns)`。
- 格子约 `2.2–2.6`。每件缩放到最大边约 `1.6–1.75`：`scale = homeScale × (目标边长 / max(size))`。
- 网格在 XZ 上居中。所有中心的 Y 相同，取房间高度附近的一个正值。不要在 Y 上再叠一层，也不要落到地面以下。
- `listPosition = 格子中心 − centerOffset × 缩放系数`。
- 相机只框住这块平板：宽高由列数、行数、格子和目标边长决定，目标点是 `(0, 平板高度, 0)`。不要把原来的房间壳体算进这个包围盒。

## 收尾核对

- 爆炸后参照主体仍在原处，其余壳体也不动。
- 没有资产低于自己的原始高度，相机在地面之上。
- 引线回到原中心，并且只在爆炸模式可见。
- 列表每行都有类型、源文件和面数；锚点带「不位移」。
- 平铺后全部资产在同一水平面上，大小接近，相机框住网格而不是整间旧房间。
