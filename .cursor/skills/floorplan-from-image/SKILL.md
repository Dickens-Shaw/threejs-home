# 从图纸写户型数据

用户只附一张户型图。你自己把识图脚本跑完，再按 [huxing-pack](../huxing-pack/SKILL.md) 交一份 JSON。不要改 `js/`，不要改原图，不要做装修设计器网页。不要靠看图估墙的坐标。

定位和 [house-plan-designer](../house-plan-designer/reference/route-image.md) 的图片路线相同：抽出墙和刻度的像素，再用图上印着的毫米把像素钉成折线。户型图画得不匀，整张图乘一个比例，每面墙会差几十毫米。印刷数字才是准的。`draft.json` 里的墙是初稿，不要直接交。看图规则只在脚本跑失败时用，并且在 `notes` 里写明坐标是看图估的。

墙、门、窗、飘窗、房间、地面都写在那一份 JSON 里。图上能认出家具、且用户没说只要户型时，`furniture` 也写上，每一件带 `roomId`。对不上家具库的放进 `notes`。

脚本在 `../house-plan-designer/scripts/`，必须执行，不是参考。第一次用先装 `numpy`、`pillow`、`opencv-python`。贝壳这种隔墙只画两条细线、中间留白的图，加 `--outlined`。脚本跑不起来时，才用文末的看图规则，不要退回整图一个比例，并在 `notes` 里写明。

## 看图

先读出最外圈总宽、总深（毫米），以及每一边每一段印刷数字，原样记下。同时记下房间名、门的开向和门轴、窗、推拉门、入户门、哪面墙涂黑。图上一个尺寸都没有时，问用户要一个已知长度，并在 `notes` 写明比例是估的。

## 抽出墙和刻度

```bash
python ../house-plan-designer/scripts/analyze.py 户型图.jpg \
  --total-width <总宽> --total-height <总深> --outlined \
  --out <工作目录>/analysis
```

脚本把低饱和度的灰、黑像素收成墙，厚度取这段的中位数。它只收水平墙和竖直墙。图上的弧墙不要用脚本拆出来的碎段，沿弧的中线手写成折线：相邻两点一条直墙，弦到弧的空隙不超过大约 50 毫米，端点相接，厚度不变。门扇的开启弧线不是墙。墙角只是小圆角、尺寸仍按直角标时，写两条直交墙，圆角写进 `notes`。同一条线上两段墙之间的空隙是门窗候选：空隙里有细灰线就猜成窗，否则猜成门。墙芯更深的当承重，再对照原图图例改。`analysis.png` 上红色是承重，橙色是隔墙，紫色圈是尺寸刻度。窗洞打断的墙、细隔墙会漏，对照原图补上。

`analysis.json` 的 `scale_check` 有按宽、按高两个 mm/px。差过大约 2%，图就不是均匀比例，这个数不能用来放墙。`dims_px` 是脚本在尺寸线附近找到的点，下一步先分清再用。

## 用刻度把像素钉成毫米

印刷数字和尺寸界线配对。`dims_px` 里的点先分清。一串彼此只隔几像素的点是尺寸数字的笔画，整簇丢掉。尺寸界线是单独一根短杠，一头搭在尺寸线上，另一头指向某个墙角。`analysis.png` 上紫色圈若落在数字中间，不要拿去配毫米。少了的墙角照原图补上。同一边有两条链时，用短杠正好指到这侧墙角的那一条。另一条的数字写进 `notes`。不要平均，不要改印刷数字。

送进 `Axis` 的像素是这道墙的墙心，用 `segments_px` 里该段的 `line`。不要用外轮廓角点，也不要用短杠落在外皮上的那个点。毫米仍是印刷累计，不要因为换了像素再加减墙厚。这道墙几乎全是窗时，墙心取两端墙垛的厚度中线，不要取玻璃线。

没有刻度的隔墙也用它自己的 `line`。锚点和隔墙必须是同一种点。锚点留在外角、隔墙用墙心时，隔墙会朝外角偏大约半个墙厚。

核对：有刻度的墙，把自己的 `line` 代进这条轴，得到的毫米应接近它的累计。差到大约半个墙厚，锚点还在外皮上，改成 `line` 再算。某一段因此在 `report()` 里偏离平均更多，而且这段里的隔墙比改之前挪了超过大约 100 毫米，这道刻度原本就和隔墙是同一套像素，改回刻度像素。

```python
import sys
sys.path.insert(0, "../house-plan-designer/scripts")
from axismap import Axis, chain
X = Axis(chain([刻度像素...], [各段毫米...]))
Y = Axis(chain([刻度像素...], [各段毫米...]))
X.report()
Y.report()
```

`Axis` 在两道刻度之间线性插值，两头按靠近的那一段外推。`report()` 里某一段的 mm/px 偏离平均 3% 以上，先核对是不是读错数字或选错刻度。

刻度像素和印刷累计配对之后，`X(px)`、`Y(px)` 算出的毫米直接写成墙中线。西、北最外中线是 0。东、南最外中线是这条链的总累计，并且这道外墙从头到尾都用这个数，不要写到中途再往里收。不要把累计值再加减 100 或 120。

链上少了几百毫米的一段是错台，单独成墙。这一段的短杠指着哪道墙角，累计值只放到那道墙上。两间房看起来差不多齐，中间仍有一段印刷毫米时，不要并成同一条线。

外墙和隔墙 `thick` 写 200。飘窗、凹槽的侧墙写 100。`segments_px` 里的像素厚度只用来分辨这种薄侧墙，不参与坐标。同一直线上厚墙接薄墙时，看原图哪一侧墙线是连续的。

门窗洞口两端的像素走同一条轴，换成离这面墙 `wall.a` 的 `t` 和 `len`。写成 `openings`，不要沿用初稿里的 `from` / `to`。门洞的 `len` 量到两侧实墙垛恢复厚度的地方。只量墙带中间的白缝时，门框已经算进墙里，洞宽会少一截，常常只剩 610 到 720 毫米。白缝比墙垛间距窄时，用墙垛间距，再对照门扇弧的半径。

画在墙厚里面的双线是窗，写 `openings`。玻璃凸出外墙、自己带侧墙时才写 `bays`。不要把平窗改成飘窗。

不要把某一边各段加总后当成整栋总宽或总高。上下、左右的合计可以不同。退进或凸出一两百毫米也要另起一条墙。只有图上同一条连续直线才共用一个 x 或 y。

一张图钉完之后墙面落在哪，见 [examples.md](examples.md)。别的图不要抄那组像素和毫米，也不要写进给外部模型的提示词。

## 脚本跑不起来时

外部模型不会执行贴进去的 Python。中线和墙厚仍按上面的规则，不要改成另一套。没有像素时，没有短杠正对的墙改用看图比例：

1. 四边尺寸链按印刷顺序原样记下。同一边有两条时，用刻度正好指到墙角的那一条，另一条和差值写进 notes，不要平均。
2. 刻度正对的墙，中线等于前面各段印刷毫米相加。几百毫米的错台单独成墙，只放到短杠指着的那道墙角上。
3. 没有刻度正对的隔墙和门窗，中线 = 前一道累计 + 比例 × 这一段自己的印刷毫米。算式写进 notes。不要收成整百，也不要用整张图一个比例。

## 交出去之前

- 每条隔墙只出现一次，两端落在中线上。隔墙和它两端的锚点是同一种点。锚点留在外角、把隔墙推出大约半个墙厚时，锚点已改到墙心。
- 该共线的墙在同一 x 或同一 y。错台还在。
- 门洞 `len` 到两侧墙垛，不是墙带中间的白缝。
- 每个房间有 `at`，点在房间里面，不在墙上。
- 飘窗是 `bays` 里的一条，不是三面手画墙。`counted` 为 false。
- `dims` 留空。印刷分段是墙面到墙面，导入后按墙中线现算。
- 有家具时，`roomId` 等于某个 `rooms[].id`。
- `notes` 写清：跑了脚本就写按宽和按高的 mm/px；没跑脚本就写每道无刻度隔墙的分数算式。还要写用了哪条尺寸链、舍了哪条以及差多少，以及窗台高、层高这类图上没有的数。
