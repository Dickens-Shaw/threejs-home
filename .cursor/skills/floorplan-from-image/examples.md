# 三室一厅一卫

这张贝壳图只说明刻度钉完之后，墙面落在哪。别的户型不要抄这些数字，也不要写进给外部模型的提示词。

## 为什么不能乘一个比例

这张图按宽 18.25 mm/px，按高 18.81 mm/px，差大约 3%。墙如果乘这一个数，每面墙会差几十毫米。墙面用下面的折线。

## 第 2 步的折线

水平外轮廓角点是像素 287、400、535、642、712，那是外角。轴上用这些墙的墙心 294、407、536、638、706，对上中线 0、2135、4585、6491、7776。上边印刷链是 `2135 / 2450 / 1906 / 1285`。东墙大部分是窗，706 是两端墙垛的中线，不是玻璃线。角点直接拿来插值时，卧室 B 西墙会偏大约 130 毫米。

竖直外皮刻度是像素 102、217、250、422、574、648，墙心大约是 108、224、254、417、564、642。这张图竖直轴仍用 102、217、250、422、574、648。422 和 574 已经和中间隔墙的像素是同一套，改成 417 和 564 会把卫生间北墙、厨房北墙推远一百多毫米。中线仍是 0、2235、2814、6060、8855、10212。右侧印刷链是 `2235 / 579 / 3246 / 2795 / 1357`。

左侧合计比右侧大约多 120（2259 对 2235，616 对 579）。下边和上边也对不齐。用刻度落在墙角的那一侧。另一侧写进 `notes`。不要平均，不要把 579 改成 457，也不要把下边改成跟上边对齐的中线距。

这些累计值直接写中线，不要再加减 100 或 120。西、北最外中线是 0。东、南最外中线是这条链的总累计。外墙和隔墙 thick 写 200，飘窗侧墙写 100。

门窗的 `t`、`len` 用同一条折线，从这面墙的起点量到洞口两边。门洞量到两侧墙垛，不要只量白缝。这张图的窗是画在墙厚里的双线，`bays` 留空。

## 必须共线

- 卧室 C 西墙与厨房东墙同一条 x。
- 卧室 B 西墙与卫生间西墙同一条 x。
- 卫生间南墙与卧室 A 南墙同一条 y。
- 卧室 B 北墙与卧室 C 南墙同一条 y。起居北墙是上一段累计 2235，中间的 579 单独成墙，不要并进卧室 B。
- 卧室 A 比 B 再向东凸出 1285。入户台阶在 A 的西墙，台阶以南是客厅。东外墙全程在总宽 7776 上，不要写到卧室 A 再往里收。

## 地面

卧室和客厅 `wood`，厨房 `tile600`，卫生间 `antislip`。飘窗若单独成面，`counted:false`。

家具要带 `roomId`，值等于这份 JSON 里的 `rooms[].id`。坐标用上面的折线另算。
