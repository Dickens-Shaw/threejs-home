# 三室一厅一卫

这张贝壳图只说明刻度钉完之后，墙面落在哪。别的户型不要抄这些数字，也不要写进给外部模型的提示词。

## 为什么不能乘一个比例

这张图按宽 18.25 mm/px，按高 18.81 mm/px，差大约 3%。墙如果乘这一个数，每面墙会差几十毫米。墙面用下面的折线。

## 第 2 步的折线

水平锚点是这张图像素 287、400、535、642、712，对上外皮 0、2135、4585、6491、7776。上边印刷链是 `2135 / 2450 / 1906 / 1285`。

竖直锚点对上右侧链，外皮 0、2235、2814、6060、8855、10212。右侧印刷链是 `2235 / 579 / 3246 / 2795 / 1357`。

左侧合计比右侧大约多 120（2259 对 2235，616 对 579）。下边和上边也对不齐。用刻度落在墙角的那一侧。另一侧写进 `notes`。不要平均，不要把 579 改成 457，也不要把下边改成跟上边对齐的中线距。

外墙、承重墙厚 240，隔墙厚 120。中线 = 墙面 ± 半个墙厚。原点在外皮交点，第一条外墙中线是 120。

门窗的 `t`、`len` 用同一条折线，从这面墙的起点量到洞口两边。

## 必须共线

- 卧室 C 西墙与厨房东墙同一条 x。
- 卧室 B 西墙与卫生间西墙同一条 x。
- 卫生间南墙与卧室 A 南墙同一条 y。
- 起居北墙与卧室 B 北墙同一条 y。
- 卧室 A 比 B 再向东凸出 1285。入户台阶在 A 的西墙，台阶以南是客厅。

## 地面

卧室和客厅 `wood`，厨房 `tile600`，卫生间 `antislip`。飘窗若单独成面，`counted:false`。

家具要带 `roomId`，值等于这份 JSON 里的 `rooms[].id`。坐标用上面的折线另算。

## 不要写成

应用里的 `beikePlan` 是旧的中线读法：整栋厚 200，进深坎用 457，下边被改成 `2135 / 3105 / 2536`。那份内置户型留着，新的识图不要照它的坐标抄。
