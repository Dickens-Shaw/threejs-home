# 三室一厅一卫

原图是贝壳那种带家具和印刷尺寸的户型。数据包用厚度 200。项目里的对照实现是 `beikePlan`。家具要带房间，例如卧室 C 的床：

```json
{"roomId": "bkC", "type": "bed", "name": "单人床", "cx": 3360, "cy": 1500, "w": 1200, "d": 2000, "rot": 0}
```

`roomId` 必须是同一份 JSON 里 `rooms[].id`。

## 为什么不照抄印刷数

- 左边 `2259+616+5338+2119 = 10332`，右边 `2235+457+3246+2795+1357 = 10090`，差 242。616 和 457 不是同一道坎。左边改成实际墙距：`2235 / 457 / 5736 / 2119` 这一组里，和墙共线的才保留。
- 下边 `1921 / 3015 / 2536` 和上边轴线差约一堵墙。下边改成对齐后的中线距：`2135 / 3105 / 2536`。2536 与卧室 A 的中线宽度一致，所以保留。
- 上边 `2135 / 2450 / 1906 / 1285` 落在墙上，直接用作中线分段。

## 必须共线

- 卧室 C 西墙与厨房东墙同一条 x。
- 卧室 B 西墙与卫生间西墙同一条 x。
- 卫生间南墙与卧室 A 南墙同一条 y。
- 起居北墙与卧室 B 北墙同一条 y。
- 卧室 A 比 B 再向东凸出 1285。入户台阶在 A 的西墙，台阶以南是客厅。

## 地面

卧室和客厅 `wood`，厨房 `tile600`，卫生间 `antislip`。飘窗若单独成面，`counted:false`。

## 尺寸

中线链，墙厚不单独成段。没有飘窗时自检应看到：上 `2135,2450,1906,1285`；下 `2135,3105,2536`；左 `2235,5736,2119`。这是 `geomSelfCheck` 里的断言，改规则时连断言一起改。
