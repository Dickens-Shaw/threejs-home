# 户型切换与编辑

只改 [floorplan-3d/index.html](floorplan-3d/index.html)。当前墙、窗、门、房间是常量，本地只存家具和拆改；2D 的 `renderWalls` 和 3D 的 `wallBox` 都按水平/垂直矩形画。

已定的行为：

- 一份户型是整屋：墙、窗、门、飘窗、推拉门、房间、家具、材质、拆改、量尺。当前这套连同已摆家具作为第一份，名字「三室两厅两卫」。
- 列表弹窗里看名字和俯视缩略图，可切换、新增、编辑、复制、删除。
- 新增和编辑在同一页进入编辑视图。保存时填名字（编辑预填原名），然后回到列表并切到这份户型。
- 编辑能力：正交墙和斜墙、窗、平开门、飘窗、推拉门。房间在墙改过之后按围合自动重算，再改名字和地面材质。

## 数据

新存档键 `huxing-plans-v2`：`{ activeId, plans[] }`。每份：

- `walls[]`：`{id, a:[x,y], b:[x,y], thick, type}`，中心线。水平/垂直墙由现在的矩形换算，四角与原矩形重合，第一份打开时画面不变。
- `openings[]`：窗、平开门、推拉门挂在某段墙上（沿墙位置、洞宽、窗台、窗头、开启方向、是否入户）。窗台按现在的规则写入：第一扇 1400，飘窗玻璃 450，其余 900；窗头 2400。门头 2100，竖向推拉 2400。
- `bays[]`：编辑器新建的飘窗。现有两个飘窗仍是墙和窗的几何，不重新拟合，避免外轮廓漂移。
- `lintels[]`：把 3D 里写死的两段过梁（主卧、子女房飘窗洞口）收进数据。
- `rooms[]`、`furniture`、`demolished`、`measures`、`bounds`。

旧键 `huxing-design-v1` 若已有家具、房间名、材质、拆改、量尺，合并进第一份，旧键保留不删。墙 id 用现在的 `w0`、`w1`…，已有拆改记录继续有效。

运行时不再使用那组 `const`。`applyPlan` 把当前户型交给原来的 `WALLS` / `WINS` / `DOORS` / `SLIDES` / `ROOMS` / `BOUNDS` 读取点。导出、导入改为整份户型，不再只写家具状态。

## 绘制

- 2D 墙改为中心线挤出的四边形。斜墙用同一条路径。
- 3D `wallBox` 改为沿中心线的旋转盒子；漫游碰撞用这段墙的有向矩形，不再只用轴对齐盒。
- `View3D.sync` 的建筑签名加入墙和洞口。现在只比较 `state.rooms` 和 `state.demolished`，换户型不会重建建筑。
- 入户箭头改挂在 `entry` 门上，不再写死在餐厅坐标。
- 缩略图是房间填色加墙线的 SVG，不含家具。

## 弹窗

顶栏加「户型」。弹窗列出名字和缩略图。

- 点卡片：切到该户型，退出编辑，刷新 2D/3D。
- 新增：进编辑视图，先放一个 10000×8000、墙厚 240 的外墙矩形和一间「未命名」，家具为空。
- 编辑：复制为草稿再改，取消丢弃草稿。
- 复制：名字加「副本」，新 id，留在列表。
- 删除：先确认。只剩一份时不允许删。删掉当前份则切到相邻一份。

## 编辑视图

进入后收起家具库，撤销栈清空。工具在现有选择、测量、拆改旁边增加：墙、窗、门、推拉门、飘窗。

- 画墙默认水平/垂直，按住 Shift 为任意角度。端点吸附其他端点。画完默认非承重、厚 240，右侧改类型和厚度。
- 窗、门、推拉门点在墙上放置。门可改开启侧和入户。
- 飘窗点在外墙上，默认进深 620、宽度 1800，生成两侧墙、正面窗和洞口过梁，并标上同一 `bayId`，删除时一起去掉。飘窗地面 `counted:false`。
- 拆改仍只标记非承重和矮墙，承重墙、外墙照旧拒绝。选中墙后删除是从户型里真正去掉，任何类型都可以，用来改轮廓。
- 保存弹出名字，空名字不能保存。写入库、设为当前户型、回到装修视图。

房间重算只在墙、洞口或飘窗变化后做：中心线在交点处打断，取最小围合面，丢掉外轮廓和面积过小的缝。与旧房间按重叠面积继承 id、名字、材质；对不上的叫「未命名」。没改过墙的第一份户型继续用现在手写的房间多边形（餐厅、过道、飘窗都保持原样）。

```mermaid
flowchart LR
  list[户型弹窗] -->|切换| design[装修视图]
  list -->|新增或编辑| editor[编辑视图草稿]
  editor -->|保存并命名| design
  editor -->|取消| design
```

## 核对

几何函数做三组自检：矩形外墙得到 1 个房间；L 形隔墙得到 2 个房间；斜墙四边形面积与厚度乘长度一致。第一份户型换算后的墙四角与现在的 `WALLS` 矩形一致。改完界面后先问是否打开内部浏览器，未同意就不打开。
