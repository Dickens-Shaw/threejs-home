# 电竞屋五风格重绘方案（布局一份 + 五套真几何）

## 方向（已推翻统一几何）

- 不要统一几何。`gamedesk/gamechair/sofa/bookshelf` 等在四张图里结构本来就不同，必须各画各的。
- 布局只定义物品 `id/type/cx/cy/w/d/rot`，切换主题 = 换整套绘制函数 + 材质配色。
- 五套：`station` 电竞黑原版保留不动（现有 68 case 精细 switch 即几何基线），其余四套按图重画到同等细致。

## 四套形态来源（唯一依据）

- bruno：`docs/research/4.png` + `my-room-in-3d/docs/房间规格.md`。低模、薄板、小倒角、浅橡+深灰+白、屏幕只橙色那块、品红只留墙光。
- daniel-light：`docs/research/2-white.png` + `daniels-home-office-portfolio/docs/浅色房间规格.md`。L形白板桌、四细木腿椅、暖白环境、细木腿不是铬。
- daniel-dark：`docs/research/2.png` + `深色房间规格.md`。通高暖木格架、黑金属桌+横档、铬五星脚、海军蓝布、柜内暖光。
- sooah：`docs/research/3.png` + `sooahs-room-folio/docs/房间规格.md`。矮胖大圆角、桃木+浅粉、金属只留琴架椅轮一点灰亮。

## 架构

- `js/draw-bruno.js / draw-daniel-light.js / draw-daniel-dark.js / draw-sooah.js`：各导出 `drawBruno(g,f,w,d,c,bz,R)` 等，全量覆盖 LIB 72 个 type（plan.js 实得 66 个家具 type + 卫浴厨房 type 一并画）。
- `view3d.js buildFurniture`：`station -> 旧 switch`，其余 id -> 对应新库。`drawStylePiece/drawExtraPiece` 逐步被取代后删除。
- `room-styles.js skin + furn-textures.js` 保留：各套库内部仍走 `skin.palette` 取色 + 程序贴图，保证换色只改一处。

## 接线

- `index.html`：`room-styles.js -> furn-textures.js -> draw-bruno.js -> draw-daniel-light.js -> draw-daniel-dark.js -> draw-sooah.js -> plan.js -> ... -> view3d.js`。
- 五风格并排预览（studio）直接验证：同一布局、五个真形态并排。

## 验收

- `docs/draw-acceptance.md`：每 type 一行，记参考图来源、形态要点、材质角色。
- 底线：station 并排图与现状肉眼无差；其余四套达到 station 同等零件密度。
