# sooahs-room-folio 房间规格

对照图是仓库里的 `docs/research/3.png`。物体名来自 `src/asset-views.js` 的 `TITLE_RULES` 和 `src/main.js`。墙、地、天花、水池、碰撞盒不列入。品牌、标志、招牌文字和角色只记形状和颜色。

尺寸都是按画面比例的估算，单位厘米。角色色固定为：木＝桃木，布＝浅粉或白，陶瓷＝白，铬＝浅灰亮，黑金属＝近黑，玻璃＝透明，屏幕＝浅色发光面。

## 整间房

- **媒介边界：** 黏土玩具三维。体积圆、表面哑光，像软胶和上色木块。排除照片、动漫和绘画。
- **机位和透视：** 开口朝向镜头，机位在左前方、略高于视线的斜上。近大远小，墙角和地板线向后墙汇拢，不是平行线仍平行。
- **光：** 整体是软的、偏暖的环境光，阴影短而淡，看不出硬边。画面上看不到单独的暖柜灯。屏幕是一块亮的浅色，不往桌上打出光斑。右窗更亮，但没有独立的窗光条。串灯只是一串小暖点。
- **色彩：** 主色是浅粉、桃木和白，饱和度中等偏低，偏暖。辅色是地板的浅褐和墙的灰粉。点缀是屏幕的浅色、小灯的暖黄、窗外的冷灰紫。
- **建模：** 比例偏矮胖，倒角大，棱很少。细节是成组的小块，不是写实零件。
- **材质记忆点：** 木是哑光桃木，布是浅粉或白，玻璃是清而略亮，屏幕是一块发光平面。金属很少，只在琴架和椅轮上发一点灰亮。
- **不能丢的锚点：** 两面墙加顶梁围成的开口盒子；厚木地板伸到开口外；左墙的洞洞板和伸出的木牌；后墙桌面上一台浅粉屏幕和一台浅粉机箱；右墙落地窗和一架浅紫键盘。

## 这间房共同的

- 轮廓偏厚、偏矮，方的东西也做成短粗的块，圆的东西接近球和圆饼。
- 圆角大。只有窗框、琴键和键盘还留着较小的棱。
- 主色是浅粉、桃木、白。浅紫只给键盘和电子琴，蓝只给小台灯和鱼缸里的水。
